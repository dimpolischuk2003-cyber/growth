# Accessibility annotations

Target: WCAG 2.2 AA.

- Skip link and semantic landmarks.
- One H1 on landing.
- Focus visible on controls.
- Minimum 44×44 tap targets for primary interactive controls.
- Form labels + `aria-describedby` + inline errors.
- Status region for submit result.
- FAQ controls expose expanded state and linked answer IDs.
- Readiness/segment/role content has static/no-JS fallbacks.
- Reduced-motion mode keeps all information visible.
- Video is click-to-load; final founder video still requires captions.
- Final QA still requires screen-reader and 200% zoom manual testing.
