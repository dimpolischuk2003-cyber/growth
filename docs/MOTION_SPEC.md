# Motion specification

- Motion must explain state or causality, never decorate.
- Default transition budget: 150–350 ms.
- Operating model transition: <=600 ms.
- Meter: one-time explanatory sequence after entering viewport.
- Hover never contains unique information; focus/tap reveal the same content.
- `prefers-reduced-motion: reduce`: remove transforms and long transitions; all states remain understandable.
- No autoplay carousels or heavy video players.
