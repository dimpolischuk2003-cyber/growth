# Post-launch review template

## Data quality
Are all main events firing once? Are UTM/referrer/segment/qualification fields reaching CRM?

## UX
Drop-off by form step, field errors, mobile vs desktop.

## Lead quality
Qualified lead rate, sales acceptance, main anti-ICP reasons.

## Proof behavior
Cases opened, diagnostic previews opened, segments selected.

## Decisions
Keep / Fix / Stop / Test next.
